# Listing 优化要点

## 标题公式
品牌 + 核心词 + 关键属性 + 使用场景 + 差异化
示例：AceBuds Pro 无线降噪耳机 蓝牙5.3 30H续航 IPX5防水 运动跑步

## 五点描述
1. 降噪：主动降噪 28dB，地铁通勤秒静音。
2. 续航：单次 8h / 总计 30h，快充 10 分钟用 2 小时。
3. 防水：IPX5，大汗运动不怕。
4. 连接：蓝牙 5.3 双设备切换，游戏低延迟。
5. 舒适：人体工学耳翼，狂甩不掉。

## 搜索词（Backend）
noise cancelling earbuds, sport earbuds, bluetooth 5.3 headphones, workout headphones, waterproof earbuds

## 诊断指标
- 标题长度 120-180 字符为佳，关键词密度 2-3 个核心词。
- 五点以"利益点"开头，避免只堆参数。
- 图片首图白底主图 + 场景图，CTR 通常更高。
