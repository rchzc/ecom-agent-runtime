# 耳机广告投放策略

## 预算分配
- 新品期（0-2 周）：70% 预算打关键词 "noise cancelling earbuds"、"运动耳机"，抢搜索位。
- 成长期（3-6 周）：50% 关键词 + 50% 商品定向（对标竞品 ASIN 人群）。
- 成熟期：转向品牌词防守 + 联盟营销，ACOS 目标压到 25% 以下。

## ACOS 优化
- 关键词否词：剔除 "free"、"cheap" 等低意向词，降低无效花费。
- 分匹配类型：广泛词用低竞价探量，精准词用高竞价保转化。
- 落地页：广告指向"降噪场景视频"详情页，转化率通常高于纯图文 1.5 倍。

## 预警线
- ACOS 连续 3 天 > 35% 触发预警，建议降竞价或暂停广泛匹配。
